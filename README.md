# Factory Locator - Sajai Enterprises

## Overview

Factory Locator is an interactive web application designed to help users locate manufacturing unit details and FSSAI license information for Sajai Enterprises products. Users can search by Vendor Code to retrieve complete facility information.

## Features

- **Vendor Code Search**: Dropdown-based search interface for selecting vendor codes
- **Factory Information Display**: Shows detailed manufacturing unit information
- **FSSAI License Lookup**: Displays FSSAI license numbers for each facility
- **Contact Information**: Provides contact details for customer care
- **Responsive Design**: Works seamlessly on desktop and mobile devices

## How to Use

### Searching by Vendor Code

1. Open the application in your web browser
2. Select a vendor code from the "Search Vendor Code" dropdown
3. Choose from the following options:
   - **SOL** - Sajai Enterprises Solapur
   - **SAT** - Sajai Enterprises Satara
   - **THA** - Sajai Enterprises Thane
4. The factory information will display automatically
